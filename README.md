## Featured Projects

### 🎙️ VoiceRAG

**Real-time voice-driven Retrieval-Augmented Generation assistant**

A full-stack RAG application where users can upload documents, ask questions through voice or text, retrieve relevant document chunks, and receive streamed answers.

**Built with:** Python, FastAPI, React, Whisper, Sentence Transformers, FAISS, LangChain, Groq

[View Repository](https://github.com/Yogendra-A/VoiceRAG)

---

### 🤖 ParcelPilot AI Agent

**Reliable AI support operations and deterministic tool orchestration**

Built an AI agent architecture where the LLM handles intent parsing while deterministic Python tools control execution, permissions, policies, and state-changing actions.

**Built with:** Python, FastAPI, React, OpenAI/OpenRouter, Pytest

[View Repository](https://github.com/Yogendra-A/CalQuity_Assigniment-)

---

### 🧘 Pranayama Trainer

**Real-time multimodal breathing and posture analysis**

A computer-vision and audio-ML system combining pose tracking, breathing classification, and real-time WebSocket communication to provide live feedback without wearable hardware.

**Built with:** Python, MediaPipe, OpenCV, TensorFlow/Keras, CNN-LSTM, Librosa, React, WebSockets

[View Repository](https://github.com/Yogendra-A/Real-Time-Breathing-and-Posture-Analysis-for-Pranayama)

---

### 📄 AI Resume & ATS Analyzer

**AI-powered resume and job-description matching system**

Analyzes resumes against job descriptions, calculates matching scores, identifies missing keywords, and performs ATS-oriented checks.

**Built with:** Python, Flask, React, TF-IDF, Cosine Similarity, Tailwind CSS

[View Repository](https://github.com/Yogendra-A/resume-analyzer)

**Built with:** Python, PyTorch, Webots, NumPy
